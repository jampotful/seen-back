# Graph guided multiscale cross attention for multilabel chest X ray classification

## Abstract
AbstractMulti-label chest X-ray (CXR) classification is challenging because thoracic abnormalities vary substantially in scale, visual saliency, and anatomical distribution, while disease labels often exhibit clinically meaningful dependencies. We propose a visual–semantic framework that integrates heterogeneous visual representations with graph-guided label reasoning for image-level multi-label CXR classification. The visual encoder consists of a Vision Transformer (ViT) branch and a DenseNet-121 branch with complementary inductive biases: the ViT branch provides self-attention-based content-adaptive token representations, whereas the DenseNet branch provides hierarchical convolutional feature maps with explicit spatial layouts. A multi-scale bidirectional dual cross-attention fusion (DCAF) module aligns these two representations and enables bidirectional cross-representation interaction at the and stages to construct a fused visual memory. To model label dependencies, we construct an ML-GCN-style label graph whose edges are derived from training-set conditional co-occurrence statistics and whose node features are initialized using GloVe label-name embeddings. The resulting GCN-refined label embeddings initialize the label queries of a Transformer decoder, which retrieves label-specific evidence from the fused visual memory and predicts a single logits matrix for multi-label classification. The proposed method achieves a Mean AUC of 0.849 on ChestX-ray14 following its official evaluation protocol and 0.815 on CheXpert using an internal 70%/10%/20% training/validation/testing partition. Qualitative Grad-CAM visualizations on selected cases further suggest that the proposed framework tends to produce activation patterns consistent with manually indicated visually suspicious regions; these visualizations are not intended as a formal localization evaluation. Overall, the results indicate that cross-representation visual fusion and graph-guided label-query decoding provide complementary benefits for multi-label CXR classification.Subject terms: Computational biology and bioinformatics, Mathematics and computing

## Introduction
Chest X-ray (CXR) imaging is widely used for thoracic assessment because it is inexpensive, rapidly acquired, and broadly available in clinical practice. A single radiograph may contain multiple abnormalities, such as pleural effusion with atelectasis or cardiomegaly with pulmonary edema. Automated CXR interpretation is therefore naturally formulated as an image-level multi-label classification problem, in which several pathological findings must be predicted from the same image. Large-scale datasets such as ChestX-ray14 and CheXpert have accelerated the development of deep-learning systems for CXR analysis1,2. Nevertheless, reliable multi-label diagnosis remains difficult because abnormalities differ in lesion size, boundary clarity, radiographic appearance, and label frequency.
Convolutional neural networks (CNNs) have been widely used for CXR classification. For example, CheXNet uses DenseNet-121 to encode radiographic patterns through local filtering, weight sharing, and hierarchical downsampling3. Such convolutional inductive biases are useful for preserving spatially organized anatomical and textural structures. Vision Transformers (ViTs), by contrast, represent an image as a sequence of patch tokens and use self-attention to model content-adaptive interactions across distant image regions4. ViTs are therefore well suited for modeling long-range interactions among patch tokens, which can complement the spatial inductive biases of convolutional networks in CXR analysis. It should be noted that the distinction between CNNs and ViTs should not be interpreted as an absolutely rigid local–global separation. Deep convolutional layers can also encode broad contextual information as their receptive field expands, and ViT tokens still originate from local image patches. Nevertheless, CNNs and ViTs provide different inductive biases: DenseNet offers hierarchical convolutional features with explicit spatial layouts, whereas ViT provides self-attention-based token interactions for long-range relational modeling. In this work, we therefore view DenseNet and ViT as heterogeneous visual encoders with complementary representational properties rather than as strictly separated local and global branches.
Existing hybrid CNN–Transformer architectures often combine features through late concatenation, reweighting, or one-way attention5,6. These fusion strategies may be insufficient for CXR classification because disease evidence can appear at different spatial scales and may require interaction between spatially organized convolutional maps and self-attention-based token representations. To address this issue, we introduce a multi-scale bidirectional dual cross-attention fusion (DCAF) module. DCAF aligns DenseNet feature maps and ViT token features at the and stages and enables bidirectional cross-representation refinement before constructing the visual memory used by the decoder.
Label dependency is another important challenge in multi-label CXR classification. Many methods treat each disease as an independent binary target, although thoracic findings often co-occur or imply related clinical conditions. Graph-based approaches such as ML-GCN model label correlations through a graph built from co-occurrence statistics7, while decoder-based methods such as Query2Label formulate multi-label prediction as label-query-based evidence retrieval8. However, learned label queries may lack explicit label-prior structure, and graph-based priors are often used as classifier parameters rather than being directly coupled with visual evidence retrieval. We address this limitation by constructing an ML-GCN-style directed label graph from training-set conditional co-occurrence statistics, initializing graph nodes with GloVe label-name embeddings, and using the GCN-refined label embeddings to initialize Transformer decoder queries. In this way, label-prior information participates directly in label-to-image evidence retrieval.
The key contributions of this work are summarized as follows:
We propose a heterogeneous ViT–DenseNet visual encoder with a multi-scale bidirectional DCAF module. Unlike late concatenation or one-way fusion, DCAF aligns convolutional feature maps and Transformer token features at the and stages and enables bidirectional cross-representation refinement.
We introduce a graph-guided label-aware Transformer decoder for multi-label CXR classification. The decoder queries are initialized by GCN-refined label embeddings obtained from an ML-GCN-style graph whose edges come from training-set conditional co-occurrence statistics and whose node features are initialized from GloVe label-name embeddings.
We evaluate the proposed framework on ChestX-ray14 and CheXpert and analyze its major components through comparison studies, fine-grained ablations, multi-run averaged evaluation, computational profiling, healthy-sample analysis, and preliminary shared-label cross-dataset analysis. These experiments are designed to assess classification performance, the contribution of visual fusion and label-prior-guided decoding, and the behavior of the final model under complementary analysis settings.

## Related work

## CNN-based multi-label classification for chest X-rays
Public benchmarks enable systematic evaluation of multi-label CXR classification. ChestX-ray8/14 provide weak image-level labels and support joint prediction and coarse localization of common findings1. CheXpert further introduces uncertainty labels and an expert comparison protocol, which better reflects clinical reporting practice2. MIMIC-CXR aligns radiographs with free-text reports and supports subsequent progress in weakly supervised learning and representation pretraining9. Early multi-label CXR models were largely built on CNN backbones. CheXNet, using DenseNet-121, established a strong baseline and popularized the paradigm of independent sigmoid outputs for multi-label prediction3,10. Subsequent improvements commonly followed three directions. First, attention-based designs enhanced localization: AG-CNN introduces attention-guided refinement to highlight disease-relevant patterns, and CRAL learns category-wise attention to highlight discriminative patterns under comorbidity11,12. Second, structured clinical priors were introduced to reduce semantic inconsistency under noisy supervision, such as hierarchical disease dependencies and uncertainty-aware training13. Third, long-tailed label imbalance was addressed by asymmetric objectives and related designs that sharpen decision boundaries for rare findings14,15. Nevertheless, many CNN pipelines still rely on global pooling and independent sigmoid heads. This weakens long-range anatomical reasoning and leaves label dependency learning largely implicit, motivating hybrid encoders and explicit label-aware inference.

## Vision transformers for chest X-ray classification
Vision Transformers (ViTs) use self-attention to perform content-adaptive token interaction, which makes them effective for modeling relationships among image patches in chest radiographs4. The Swin Transformer introduces a hierarchical shifted-window mechanism to improve computational efficiency while preserving multi-scale representation learning16. CXR-specific variants, such as IEViT, further adapt Transformer architectures to enhance sensitivity to subtle lesions and low-contrast textural patterns17.
In medical imaging, the effectiveness of Transformer-based models is often shaped by both training-set scale and supervision quality. Park et al. use knowledge distillation to stabilize training and improve generalization in CXR diagnosis18. Self-supervised pretraining has also emerged as an effective strategy. CheXzero demonstrates that large-scale self-supervised learning can support expert-level pathology detection even without manual labels19. Masked autoencoder (MAE) and self-distillation frameworks, such as DINO and DINOv2, learn transferable representations for downstream tasks20–22. DINO-CXR further demonstrates improved multi-label recognition when annotated data are limited23. However, pure Transformer models may lack the explicit spatial continuity provided by convolutional feature maps, and their training can be less robust in the presence of label noise or limited data. These limitations motivate hybrid designs that combine CNN-style spatial inductive biases with Transformer-based content-adaptive token interactions.

## Multi-label decoding and cross-attention-based evidence retrieval
Conventional multi-label CXR classifiers often compress an image into a single pooled representation and predict labels with independent sigmoid heads. This can dilute localized evidence and provides limited mechanisms for consistent prediction under comorbidity. Transformer decoders provide a more structured alternative by maintaining label queries and retrieving relevant visual evidence through cross-attention24. Query2Label formulates multi-label classification as label-conditioned evidence retrieval by treating each label as a learnable query8. ML-Decoder scales this paradigm and supports semantic initialization with word vectors to improve generalization on long-tailed categories25. CXR-oriented decoders further extend this line: TransDD aggregates complementary visual evidence with a dual-path decoder, while Label Correlation Transformer explicitly models label relations and improves evidence aggregation26,27. Many existing decoder-based methods learn queries from random initialization or weak semantic priors and rely on single-scale visual memory. This can limit fine-grained retrieval and reduce robustness when label correlations shift across datasets. These limitations motivate the use of label-prior-guided queries together with multi-scale fused visual memory for evidence retrieval.

## CNN–transformer hybrid encoding and multi-scale feature fusion
Hybrid encoders aim to combine convolutional inductive biases with attention-based token interaction. CoAtNet integrates convolution and attention across stages to improve generalization across data regimes28. MaxViT further enhances non-local token interaction via multi-axis attention while keeping computation manageable29. In CXR studies, two-branch architectures often compute CNN and Transformer features separately and fuse them only before prediction5,6. Many designs use concatenation or weighted summation, which limits how much one representation can correct the other during feature learning. This becomes critical when small lesions and widespread structural abnormalities must be recognized simultaneously. These observations motivate a fusion strategy that aligns heterogeneous visual features at multiple scales and uses bidirectional cross-attention to promote cross-representation refinement.

## Label dependency modeling and prior-driven joint reasoning
Multi-label CXR prediction involves rich inter-label structure, including co-occurrence patterns, mutual exclusivity, and clinically meaningful complication pathways. Accordingly, graph-based approaches have been widely explored to model such dependencies. ML-GCN constructs a label graph from co-occurrence statistics and uses graph convolution to learn label embeddings, which are then used to parameterize interdependent classifiers7. Beyond label graphs, ImageGCN models inter-image relationships to improve representation consistency and disease identification30. More recent studies have explored correlation-guided label feature learning, unified correlation integration frameworks, and interpretable prediction through label embeddings31–33. In multi-label CXR classification, jointly modeling visual evidence and label co-occurrence priors has also been shown to benefit the analysis of complex cases34.
Despite these advances, two limitations remain. First, label semantics and co-occurrence-derived graph structure are often incorporated in separate stages, making it difficult to couple label priors with visual evidence retrieval. Second, label priors are frequently used only for static classifier construction or post hoc recalibration, rather than being tightly integrated with evidence retrieval during inference. These limitations motivate an ML-GCN-style label graph whose edges are derived from training-set conditional co-occurrence statistics and whose node features are initialized from semantic label embeddings; the resulting label priors are injected directly into decoder queries.
Taken together, prior studies have advanced multi-label CXR classification through stronger CNN backbones, Transformer-based context modeling, hybrid visual encoders, decoder-based evidence retrieval, and graph-based label dependency modeling. However, unified frameworks that combine deep multi-scale visual fusion with label-prior-guided decoding remain underexplored. This gap motivates the visual–semantic framework proposed in this work, which couples a parallel ViT–DenseNet encoder with a graph-guided Transformer decoder for end-to-end integration of heterogeneous visual evidence and label priors.

## Handling of the No Finding label
The No Finding label denotes the absence of annotated abnormalities and is not treated as a conventional disease category. For ChestX-ray14, the reported Mean AUC is computed over the 14 disease labels, and No Finding is not included in the disease-label graph used for label reasoning. For CheXpert, when No Finding is included in the 14-label setting, we avoid using its co-occurrence with disease labels as disease-promoting graph edges. Instead, No Finding is handled as a healthy-state indicator with its own label representation. The final prediction is still determined by label-conditioned visual evidence retrieved from the fused visual memory, rather than being forced by graph priors alone.

## Experiments
The experiments are organized in a layered manner to improve readability and to keep the evaluation logic explicit. We first describe the datasets, evaluation protocols, label co-occurrence statistics, and implementation details. We then report the main comparison results as averages over three independent runs (seeds 0, 1, and 2), followed by component-level and fine-grained ablation studies. ## Datasets and evaluation protocols
We evaluate the proposed framework on two widely used benchmarks for multi-label chest X-ray (CXR) classification: ChestX-ray14 and CheXpert.

## ChestX-ray14
The NIH ChestX-ray14 dataset contains 112,120 frontal chest radiographs collected from 32,717 patients and annotated with 14 thoracic disease labels1. We follow the official ChestX-ray14 evaluation protocol, using 86,524 images for model training and 25,596 images for testing. The original annotation system also includes a No Finding label; however, consistent with the evaluation protocol adopted in this work, the reported Mean AUC is averaged over the 14 disease labels only. ## CheXpert
CheXpert is a large-scale CXR dataset that includes uncertainty labels2. The DenseNet branch was initialized with ImageNet-pretrained DenseNet-121 weights, whereas the Transformer branch used vit_base_patch16_384 initialized from an MAE-pretrained checkpoint when specified. Before supervised training on ChestX-ray14 and CheXpert, we further pretrained the visual encoder on the MIMIC-CXR-JPG dataset to adapt it to the appearance of chest radiographs and common thoracic pathology patterns35. MAE and CXR-specific pretraining are treated as initialization strategies and do not imply that the ViT branch is specialized to a single spatial range. Afterward, the full network was fine-tuned end to end on each target benchmark. Data augmentation included random resized cropping, horizontal flipping, rotation within , brightness/contrast jitter with factor 0.2, and random erasing. During validation and testing, we used deterministic resizing together with the same normalization pipeline.

For the fusion-mechanism comparison, simple concatenation and weighted summation perform worse than attention-based fusion, indicating that static feature combination is insufficient for fully exploiting the complementary properties of DenseNet feature maps and ViT token representations. The two unidirectional DCAF variants improve the Mean AUC compared with static fusion, which supports the effectiveness of cross-representation attention. This suggests that mutual refinement between convolutional features and Transformer tokens is important: ViT tokens provide long-range relational cues for convolutional feature refinement, while DenseNet feature maps complement Transformer tokens with spatially organized visual evidence. Overall, these results support the use of fusion with bidirectional DCAF as the default configuration.

Table 12 evaluates whether the performance gain of the proposed framework is accompanied by acceptable computational overhead. However, because the datasets used in this study provide image-level labels rather than pixel-level lesion masks, these Grad-CAM results should be interpreted only as supportive visual evidence and not as proof of localization accuracy.

## Conclusion
We presented a visual–semantic framework for image-level multi-label CXR classification that integrates heterogeneous visual representations with graph-guided label-aware decoding. The DenseNet–ViT encoder and DCAF module construct a multi-scale visual memory, while the ML-GCN-style label graph initializes decoder queries with co-occurrence-based structural priors and semantic label-name embeddings. Within the experiments reported here, the method achieves a Mean AUC of 0.849 on ChestX-ray14 following its official evaluation protocol and 0.815 on CheXpert using the internal 70%/10%/20% training/validation/testing partition described above. The multi-run averaged results, efficiency analysis, fine-grained ablations, healthy-sample behavior analysis, and preliminary shared-label cross-dataset analysis provide additional perspectives for characterizing robustness, computational cost, and cross-dataset behavior. These findings support the value of coupling cross-representation visual fusion with label-prior-guided evidence retrieval, while broader multi-center validation remains necessary before drawing strong conclusions about clinical deployment. Future work will also investigate how the current framework can interact with medical visual foundation models and biomedical vision–language pretraining, which may provide richer region-level priors and stronger semantic alignment under limited annotations and domain shift.

## Figure Fig. 1: Overall architecture of the proposed framework. The model uses DenseNet-121 and ViT as heterogeneous visual encoders, applies DCAF to obtain the fused visual memory, initializes label queries with GCN-refined label embeddings, and predicts a single logits matrix Z for multi-label classification. The circled “C” denotes feature concatenation, and the sigmoid layer converts logits into label probabilities.

## Figure Fig. 2: Principle of the cross-attention operation used in DCAF. The query feature interacts with the key feature through scaled dot-product attention to generate normalized attention weights, which are then applied to the value feature to aggregate source information. In DCAF, this operation is performed in both directions between DenseNet convolutional feature maps and ViT token features.
