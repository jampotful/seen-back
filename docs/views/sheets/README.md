# Sensing sheets

One sheet a group, written before anything is drawn. Each row of a sheet carries a grade (measured in this animal, measured in a relative or a wider group, a guess, or left out) and a source. Each sheet was written by one research agent and checked by a second that had not seen it; the second agent's notes are in `<group>.audit.md`, and the sheet beside them is the corrected one.

| Sheet | Views it proposes | Checked |
|---|---|---|
| `spider.md` | jumping spider; spider (every other spider) | yes |
| `fish.md` | fish; shark and ray | yes |
| `bat.md` | bat; flying fox | yes |
| `tick.md` | tick (mites stay out) | yes |
| `fungus.md` | fungus (lichens included); slime mould | yes |

The plan these feed is `docs/COVERAGE.md`.
