# Sensing sheets

One sheet a group, written before anything is drawn. Each row of a sheet carries a grade (measured in this animal, measured in a relative or a wider group, a guess, or left out) and a source. Each sheet was written by one research agent and checked by a second that had not seen it (the first five on 11 and 12 October, the next five on 12 October 2026); the second agent's notes are in `<group>.audit.md`, and the sheet beside them is the corrected one.
