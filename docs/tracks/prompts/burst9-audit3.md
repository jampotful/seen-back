3. **Prepare the application.** Write corrected copies of every audited log with `tools/views/apply_audit.py` to `docs/views/audit/corrected/<unit>.jsonl`, using your decided rule (a decision file `docs/views/audit/decisions.jsonl` if the script needs one; extend the script and its test if so). Never edit a log in place. Write `docs/views/audit/SAMPLE.md`: the method, the counts, ten example rows each way, the rule decided, and how many records change grade in each unit. Keep the writing plain, in US English, with no fragments and no "not X but Y".
