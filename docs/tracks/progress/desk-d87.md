# desk-d87 progress (regional open-access journals of Iran, Turkey, Pakistan)

Started and finished 29 October 2026. Branch research/desk-d87. About 25 WebSearches and 45 fetches. 6 evidence records in docs/views/evidence/desk-d87.jsonl (check.py: 0 problems), no search records, no wanted lines. All text came through WebFetch, which refuses verbatim abstracts over 125 characters, so every quote is a sentence WebFetch returned whole with its character count; the Liquidambar record is marked partial (abstract page only). Journal hosts only (dergipark.org.tr, pakbs.org, jdesert.ut.ac.ir); no proxy, ResearchGate or academia.edu result was opened. GBIF species keys were opened for all six accepted names (in each note).
