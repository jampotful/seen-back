## Line 1, Pseudocrangonyx concavus, eyes_count 0

Head sentence verbatim from adjoining pieces: "Head (Fig. 1B) as long as pereonite 1; rostrum reduced, without minute setae; lateral cephalic lobe anteriorly expanded," / "apex rounded, slightly dilated anteroventrally; antennal sinus not deep; eye absent." Whole sentence, no cut, 29 words; value 0 says no more. Type locality "Hwansangul Cave, Samcheok-si, Gangwon-do, South Korea". Holotype printed "Holotype: 1 female, 9.2 mm, NIBRIV0000862807."; paratypes "4 specimens, NIBRIV0000872407", plus a male (5.5 mm, NIBRIV0000872409) in the material. No other eye, pigment or ommatidia sentence in Diagnosis or Remarks, so no contrary result omitted.

Fault (scientific meaning, applicability): the Description opens "Holotype female: Body (Fig. 1A) approximately 9.2 mm long." It is a description of one specimen; there is no male description. The record's `method` says "the Description does not say it is limited to the holotype", which misstates the page and widens the stated basis of the absence from one female to an unspecified series. Under the 29 Oct counting rule this changes applicability, and nothing else in the record corrects it. Verdict **correct** (method, conditions). Uncounted: habitat "cave/groundwater" changed to the printed cave locality; fixation sentence and register check added.
