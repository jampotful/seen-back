## Trait decision

Kept eye_diameter_mm. The run-in label "Eye interdistances and diameters" is followed by two hyphenated pair-figures (PME–PME, PME–ALE), which are interdistances, and one single-eye figure (PME), which can only be the "diameters" half of the label; the PME value is therefore fairly read as a printed eye diameter. The same Pholcidae sentence is already on main as eye_diameter_mm (desk-d322, d362, d381, d382, all audited). The Methods give no eye definition, so the call rests on the label alone. OWNER QUESTION: the ruling names the label "Eye diameter(s)"; does the combined label "Eye interdistances and diameters" meet it, or should these lines and the earlier Pholcidae lines on main all move to sensory_anatomy together? If the owner says the latter, change `trait` only; everything else in the Replacement stands.
