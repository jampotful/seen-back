# desk-d151 progress (animal vein: thin vision cells)

Scope: vision traits in animal groups with few records on main. Grepped docs/views evidence and audit/corrected by genus for about 80 genera across arachnids, myriapods, stomatopods, cephalopods, gastropods, tunicates, agnathans, mammals and insects. No hit on main for Ephoron, Haliotis, Hermissenda, Idiosepia, Placopecten and Pyrrhocoris; one file each for Aurelia, Centruroides, Chiton, Ciona, Dolomedes, Doryteuthis, Dytiscus, Eptatretus, Euprymna, Lithobius, Loligo, Lymnaea, Tegenaria. Only the Ephoron lead was worked this session.

Records: 6 in docs/views/evidence/desk-d151.jsonl, all grade m, Ephoron virgo (Polymitarcyidae, Ephemeroptera; GBIF ACCEPTED), lambda_max_nm, Egri, Mészáros and Kriska 2022, Proc R Soc B 289(1973):20220318, 10.1098/rspb.2022.0318.
