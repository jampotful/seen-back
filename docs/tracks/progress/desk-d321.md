# desk-d321

Task: open-access physiological and behavioural threshold papers (lambda_max_nm, cff_hz, sense_hearing, sense_electric, sense_magnetic) for species not on main. 0 records filed; no evidence file written. WebSearch used: 48 of about 50; WebFetch used for each candidate page.

## Result

Every open-licence threshold paper the searches surfaced was already on main by DOI, by species, or both. No record was filed rather than file one that repeats main or rests on a page I could not read with a licence statement.
