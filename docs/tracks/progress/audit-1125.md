## Key question: sentence record versus table-row record

Each species carries a description-sentence record (a ratio of tympanum to eye diameter) and a table-row record (absolute TD in mm for the same holotype). These are two distinct quantities: the mm value cannot be recovered from the ratio, and the ratio is printed as its own finding. Main has the same pattern of one sentence yielding separate TD and ED rows (desk-d344, d365), and desk-d332 Sphaerotheca maskeyi carries a ratio with mm values in one record. Neither record pools specimens: both are the holotype only. So the pairs are not duplicates and not pooled, provided each record names the other and any text-versus-table disagreement. For marokoroko the paper disagrees with itself: the text prints 64.5%, while Table 2 holotype TD 2.5 / ED 3.8 gives 65.8%. The unit did not flag this (for G. matsilo it dropped a larger disagreement). For lomorina, 2.1/4.0 = 52.5%, consistent with 53%. For asimus, 1.9/4.3 = 0.44, consistent with 'slightly less than half'. Row labels: all three table quotes print the row label (the 'TD' label for marokoroko, which is a row-per-measurement table; the specimen code for lomorina and asimus, which are row-per-specimen tables). The column header row is given in conditions, as in desk-d365.

Form against main: the tympanum ratio rows on main (desk-d366 Choerophryne multisyllaba 0.42; desk-d574 Vitreorana micaelae 0.428, Leptobrachella wumingensis 0.49, Pristimantis fergusoni 0.52) give a numeric value with units 'ratio'. Lines 1 and 3 give a descriptive string with units 'percent of eye diameter'. This is corrected to 0.645 and 0.53 'ratio'. Line 5 has no number ('slightly less than half'), so it keeps its string value with 'fraction of eye diameter', like the desk-d332 Raorchestes ghatei row. Trait and kind (sensory_anatomy / anatomical_measurement) fit EVIDENCE-INTAKE.md and main. No line is eye_diameter_mm, so no trait move arises. ED is a defined diameter in all three Methods, and the printed unit is mm. The hearing stimulus-level precedent was not applied.
