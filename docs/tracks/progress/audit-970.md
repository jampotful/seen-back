## Discrepancy ruling
The holotype Description prints '… HL 11.5 mm, HW 7.6 mm, HH 5.7 mm; eye moderate, ED 2.3 mm; […]' (sentence opens 'An adult male with TL 322 mm …'), i.e. HL 11.46 and ED 2.26 rounded. The holotype value is therefore the same printed measure in two places, not a table slip or a different measure. Holotype and QHU paratypes have ED/HL about 0.19-0.20; the CIB paratypes about 0.30-0.36 (my arithmetic from printed cells). The paper says nothing (Variation, Comparisons, Discussion print no eye sentence). No contrary value is printed and none is omitted: the unit filed values as printed and listed every other value and the spread in `conditions`. Ruling: not an error for any line; the spread stays a disclosed weak spot. The unit's note called the Description value something that 'differs' from 2.26 while calling it rounded, and quoted the mid-sentence piece 'eye moderate, ED 2.3 mm;' with no cut mark (fault, corrected).
