## Checks common to all 8 lines
- Methods definition: both papers print an EYE-diameter definition. Odorrana: 'ED eye diameter (distance from the anterior corner to the posterior corner of the eye);' under Materials and methods > Morphological comparisons; Rhacophorus: Table 1 row 'ED | Diameter of eye'. Unit mm printed (Odorrana Table 4 caption 'Units are given in mm.'; Rhacophorus Table 2 caption 'Measurements (mm) …'). The trait stays eye_diameter_mm and nothing moves to sensory_anatomy.
- Values: every value matches its printed column digit for digit (Odorrana ED row 4.94 | 4.1–4.9 | 4.5 ± 0.3 | 5.8; Rhacophorus ED row 4.2 4.6 4.3 4.4 4.4 4.2 4.4 3.6 against header SWU 0008699, 0008599, 0008600, 0008601, 0008602, 0008603, 0008604, 0008701). The page prints no space after a decimal point. The quotes are whole table rows with the code label only (7 and 9 words).
- Ratio check: the Odorrana holotype clause 'eye large and convex, ED 0.73 SL;' agrees with 4.94/6.73. The Rhacophorus holotype clause '(ED 4.2 mm)' agrees with Table 2.
- Repeats: git grep of origin/main docs/ for both species names and both DOIs finds pupil_shape and sensory_anatomy rows (desk-d582, d583, d645) and no eye_diameter_mm value. The d582 TD row contains the clause 'ED 4.2 mm', but its value and trait are the tympanum, so line 4 does not repeat it. No line is a repeat.
- Taxonomy: ASW lists both names as valid with no synonymy or split. Odorrana leishanensis: 'Li, Chen, Su, Liu, Tang, and Wang, 2024', 'Holotype: MT LS20230729013'. Rhacophorus medogensis: 'Weng, Liu, Li, Yu, and Huang, 2025', 'Holotype. SWU 0008699'. Families (Ranidae, Rhacophoridae) are given by the ASW paths.
- Source: bylines, titles, DOIs and volume/issue/pages match the pages (Odorrana: ZooKeys 1192: 57-82; Rhacophorus: Zoosystematics and Evolution 101(2): 437-447). The licence sentence (CC BY 4.0) is whole and correct in both. No Class, Order or Family heading is printed in either paper. unit = desk-d647 on all lines.
