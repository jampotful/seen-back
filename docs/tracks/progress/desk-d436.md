# desk-d436 progress

Angle: eye-size records, wider net, thirty-first round. 36 records from three open Pensoft ZooKeys papers (log docs/views/evidence/desk-d436.jsonl). Pensoft XML reached through my own search results; the fetch tool summarises long pages, so type lines and Methods came back in pieces or paraphrase and are said so in each record.
