- F7 (lines 41-48): no heading path statement (the paper prints no Class, Order or Family heading; Table 2 sits in the Discussion) and the overlap note is stale (DOI now on main for the five d518 species as well); the pseudo-replication sentence ('mean values per call type within recordings') is also missing. source.url pointed to the PMC article page, which was not the copy read; set to the PDF copy read, as in d518.
