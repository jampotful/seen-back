## Skipped and why
- Vietnamophryne abscondita: Methods define EL, not ED (brief).
- Microhyla ninhthuanensis, M. daklakensis (ZooKeys 1036): Methods define eye length only; no ED row.
- Micryletta hekouensis (Herpetozoa 34): only EL (eye length) defined; the holotype sentence calls it "eye diameter (EL ...)" but the definition is EL.
- Cyrtodactylus zhenkangensis, C. menglianensis (both Liu & Rao, ZooKeys): ED = ear diameter; eye is OD (orbit).
- C. arnei (ZooKeys 1253): ED = ear length; eye is OD. C. jayadityai (EJT 1048): no ED; OD (orbit diameter) only.
- Lycodon walli (ZooKeys 1251) and Bungarus suzhenae (JoTT 16(6)): Methods define no eye measurement. Lycodon irwini (Evol. Syst. 9(2)): Methods define none (Table 1 prints an "Eye dia" row outside Methods).
- Boulenophrys lichun (ZooKeys 1216): holotype text ED 0.34 of HDL conflicts with Table 2 (ED 4.8, HDL 13.3 = 0.36); whole species not filed because a column mix-up would affect paratype cells too.
- Theloderma khoii (EJT 794): holotype text ED 4.7 mm vs Table 3 4.6; table columns garbled.
- Phyllodytes gravata (EJT 1048): ED defined, but only ratios in text and a jumbled table header (header names MZUESC 23889 as holotype, text says it is the female paratype).
- Amnihyla hastula (Vertebrate Zoology 73): eye is EYE (horizontal diameter), no unit stated for the ocular-micrometer measurements (Table 1 values 4, 4, 3.8, 4, 5).
- Scutiger kanjiroba (ZooKeys 1210): eye only as EHD/HL ratio; measurement table is supplementary.
