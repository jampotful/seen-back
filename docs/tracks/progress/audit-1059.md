Faults:
- a (counted, all 8): provenance misstated. The method gives only released bats in clearings 'and free-flying recordings in Bolivia, Brazil and Panama'. The paper records in 'Costa Rica, Panama, Venezuela, Bolivia, and Brazil over a period of 10 years', with released bats in Costa Rica and Panama and Venezuelan reference recordings of high-flying individuals 'collected with a shotgun', and never assigns species to sites or methods. For E. dabbenei the error bites: MDD lists it only for Argentina, Brazil, Colombia, Paraguay and Venezuela, so the method's country list points at Bolivia and Panama and drops Venezuela, one of only two paper countries inside its range. The pseudo-replication note ('mean values per call type within recordings') was also omitted. (Unlike audit 1046's wording, this audit reads 'free flying molossids in Bolivia, ... in Brazil ..., and in Panama' as one sentence covering all three countries; the unit's 'free-flying' for Brazil is right.)
- b (counted, all 8): conditions say 'the same species is also printed with a second call type that is not filed here'. False for both species: Table 3 prints two call types each (E. dabbenei Low 22/6 and High 23/6, lines 16-21; E. nanus Low 8/4 and High 9/4, lines 22-27), and all are filed in this unit.
- c (format, all 8): where gives the table title as 'Search flight call parameters for the genera ...'; Table 3 prints 'Search flight call parameters for the genus Eumops.' Footnote described as 'read as applying to Tables 1-3', which is unnecessary for a Table 3 row.
- d (format, all 8): licence sentence cut after 'in any medium' with no cut mark and without 'Copyright: 2014 Jung et al.'; now whole. MDD status given as 'valid/living' (page prints 'Living', 'Found in the wild'). url names the PMC article page while the PDF was read; now the PDF copy.
- e (format, all 8): quotes kept the text-layer '6' for ±; the replacement decodes to ±, checked digit by digit, and the note's arithmetic check now uses the row itself, not a Neoplatymops row.

Counts: 8 lines judged, 8 errors (all fixable), 0 dropped, 0 held out. Counted faults 16 (a 8, b 8); format faults 24 (c 8, d 8, e 8).
