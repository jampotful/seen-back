Abstract: To achieve rapid and accurate identification of wild Chinese giant salamanders in
complex field environments, we propose an improved recognition model based on YOLO v
11n. This model incorporates an Efficient Multi-scale Attention Module (EMA) into the Bac
kbone layer, replaces the Complete Intersection over Union (CIoU) loss function with WiseIoU (WIoU) loss, and introduces Lightweight Adaptive Extraction of Convolutions (LAE) in
to the Head layer. Ablation and comparative experiments demonstrate that the improved mo
del achieves recall, precision, F1 score, and frame rate of 94.85%, 95.39%, 95.12%, and 77.
20 f/s, respectively. The model occupies 11.56 MB of memory and performs 8.65×10⁹ float
ing-point operations. Compared to the baseline YOLO v11n, the recall, precision, F1 score,
and frame rate are 5.70, 6.13, 5.92 percentage points higher and 27.1 fps faster, respectivel
y. The proposed YOLO v11n-EWL model demonstrates significant improvements in stability,
recognition speed, and accuracy. The improved model meets the real-time detection require
ments for wild Chinese giant salamanders in natural habitats and can sustain long-term outd
oor operation. Based on this, an all-weather image recognition and behavior detection syste
m for wild salamanders was developed, successfully detecting over 20 instances of wild Chi
nese giant salamanders. This system provides a stable and reliable monitoring tool for adva
ncing the conservation of wild salamanders and their habitats.
Key words: Chinese giant salamander; object detection; YOLO v11; Deep learning

2.2.3 Lightweight Adaptive Extraction Convolu
tion Module LAE

To enhance the speed of model recognition
and minimize memory usage, a lightweight
adaptive extraction convolution method is
implemented. The LAE module serves as an
effective feature extraction component,
enhancing the model's adaptability to intricate
scenes by dynamically modifying convolution
kernel parameters and selecting features
adaptively, all while decreasing computational

demands. The

configuration of LAE is

illustrated in Fig. 7.
In the section on Lightweight extraction,
the input image undergoes convolution in
groups, specifically with groups set to c/16. This
indicates that the input channels are segmented
into c/16 distinct groups, enhancing the
efficiency of feature extraction. Moving to the
Dimension mapping section, the convolved
features are reorganized (R), meaning the
outcomes of the group convolution are
rearranged into various spatial dimensions for
effective feature representation. The Adaptive
extraction (AE) segment involves applying
adaptive average pooling to the feature map,
which consolidates feature information across
height and width. This pooling process reduces
the spatial dimensions of the inputs, allowing
the model to concentrate more on global
features. A 1x1 convolution is then applied to the
pooled feature map, further compressing and
adjusting the number of channels. Subsequently,
the feature map is rearranged and subjected to
Softmax normalization, enabling adaptive
adjustments to the weights of each channel,
thereby enhancing the network's expressive
capabilities. Finally, the combined feature maps
are added to the input features through a residual
connection, ensuring a seamless flow of
information and producing the final feature
maps with dimensions of h/2×w/2×c.

Methods

Data acquisition and preprocessing
Image samples of the Chinese giant salamander were collected from the Zhongjian River Giant
Salamander National Nature Reserve in Xianfeng, Hubei Province between December 2024 and
February 2025. To overcome the challenge of scarcity of wild giant salamander samples, the initial
collection of 1020 original images was expanded by supplementing 530 images from public network
resources.To further enhance the diversity of the dataset and the generalization ability of the model,
we use a variety of data enhancement techniques to enrich the dataset. Rotation, sharpening,
brightness adjustment, adding noise, and HSV color space filtering are included to simulate different
weather, lighting conditions, and environmental disturbances. After enhancement, the total size of the
dataset reaches 6952 images, which effectively improves the robustness of the model in complex
environments. All images are manually annotated using X-AnyLabeling software, and the annotation
information is saved in a TXT file in YOLO format, containing the location information of the target
bounding box. The final dataset is randomly divided into training set (4866 pieces), validation set
(695 pieces), and test set (1391 pieces) according to a ratio of 7:2:1 to ensure the fairness and
reproducibility of the experiment.
Integration of efficient multi-scale attention modules (EMA).
In order to enhance the model's ability to characterize multi-scale features, especially in complex
scenes where the body color of giant salamander is mixed with the environmental background, we
use the Efficient Multi-scale Attention Module (EMA) to replace the original attention mechanism in

the Backbone network. Without reducing the channel dimension, the EMA module groups the
channels and extracts the attention weights through 1x1 and 3x3 volume integral branches
respectively, and then captures the pixel-lev·el relationship and global context information through
two-dimensional global average pooling and Sigmoid activation function, so as to significantly
improve the model's focus ability on key features.
Application of the Wise-IoU (WIoU) loss function
Aiming at the problem of uneven distribution of anchor frame mass and harmful gradient in lowquality samples in field images, we replace the original CIoU loss function with the loss function of
dynamic non-monotonic focusing mechanism. A small gradient gain is allocated to the low-quality
anchor frame, which guides the model to optimize towards the high-quality sample more stably,
improving the convergence speed and stability of training.
Introduction of Lightweight Adaptive Extraction Convolution (LAE).
In order to reduce the complexity of the model, improve the inference speed, and make it more
suitable for deployment on edge devices with limited computing resources, we have introduced a
lightweight adaptive extraction convolutional LAE module at the Head layer. Through group
convolution, dimensional rearrangement, adaptive pooling and 1x1 convolutional operations, LAE
dynamically adjusts convolutional kernel parameters and realizes adaptive feature selection,
significantly reducing the amount of floating-point operations and model parameters, while
maintaining strong feature extraction capabilities.
Experimental setup and evaluation indicators
All experiments were conducted on the Autodl computing power platform using an NVIDIA
GeForce RTX 4090 GPU (24GB of VRAM). The deep learning framework is PyTorch 2.3.0, and the
programming language is Python 3.12.3. A total of 500 epochs were trained on the model, with an
initial learning rate of 0.001 and a momentum of 0.937. To comprehensively evaluate model
performance, we use the following evaluation metrics: Precision (P), Recall (R), F1 Score, Frames
per Second (FPS), model memory footprint, and floating-point operation.
